# Modifications — 2026-10-29

- Foreground CPU decoding now includes generic stack/control and DS/FR
  instructions, reducing repeated Python dispatch while preserving instruction
  counts, traces, strict failures and host hooks. Urgent key events request one
  native update before presentation; unfinished batch claims are refunded with
  at most three owed updates retained. No BIN, audio calibration or snapshot ABI
  changes. Desktop browser checks are not physical Android performance evidence.

- R23 adds an explicit offline custody policy: feed, clean and bedtime lights
  protect against new unattended care mistakes without erasing past history.
  Native code owns sleep, growth, evolution routes and normal stage resets.
  Hash-gated event settlement skips only strictly interior countdown intervals;
  boundaries and evolution commits remain native. Existing injury, illness,
  death, unhatched pets and unsupported active flows stop without losing debt.
  Snapshots persist the policy and a committed watermark; processing time does
  not create further catch-up debt. The legacy native-care mode remains selectable.
  This is a host policy, not original-hardware offline behavior. No BIN changed.

- PenC execution caches decoded instructions and short straight-line blocks in
  an additive accelerator. Strict fallback, instruction budgets, traces, PC
  wrapping, peripheral hooks and snapshot ABI identities remain intact.
  Catch-up sends progress between presentations (about 250 ms apart), always
  presents its final/blocked state, and refreshes on cancellation without a
  game tick. This earlier acceleration leaves native care behavior unchanged;
  the later custody policy above is a separate selectable behavior.
- Homepage startup now loads the last locally remembered BIN through the existing
  profile/hash and snapshot validation path. Gameplay remains paused until a tap;
  loading locks input and exposes recoverable errors without replacing bad saves.
  No firmware distribution or download was added.
- PenC Pocket contains a Python adaptation of selected MAME 0.289 unSP
  instruction behavior, explicit peripheral/host adapters and a browser UI.
  This is not an official MAME release or a full hardware implementation.
- The initial public release added GPL notices without executable Python AST
  changes. The subsequent R23 update admits one additional exact BIN hash in
  boot, native settings, away catch-up and sound snapshot guards, after checking
  their unchanged native regions. CPU instructions and snapshot schemas remain
  unchanged; per-file download hashes are refreshed.
- R23 replaces the bundled r18/r19/r20/r19h3/r20h4 profiles. TEST4 and DMC remain.
  Older adapter admissions and stored-profile migration records are retained for
  existing local saves; no user BIN or saved state is deleted or converted to R23.
- The original browser integration used a private authenticated relay.
  Static hosting retains a null-endpoint unavailable state, with no background
  pairing attempts. QR links preserve the hosting subpath.
- Cloudflare Free deployment adds authenticated QR pairing and native packet
  mailboxes in a SQLite Durable Object. Peer acknowledgements, bounded retries,
  quotas, expiry and disconnect are explicit. Different firmware may pair with
  matching native transport hashes. The unpublished TURN prototype is omitted;
  there is no credential issuance or paid fallback. The verified Free endpoint
  is enabled after live packet, browser and native gameplay tests on 2026-10-28.
  No game core behavior changed. Physical iPhone-to-iPhone testing remains open.
- Previously bundled profiles r19h3/r20h4 omitted only `r16h.art` and `r16h.base_path`, unused local
  build metadata. `public/profile-migrations.js` records the exact admitted
  hash transition. Only that transition is allowed before normal restore
  validation; firmware/core identities and saved state are not rewritten.
- jsQR 1.4.0 is wrapped as an ES module. QR decoding logic is unchanged.
  The dated packaging notice is in its browser file and regeneration tool.
- The source package is explicitly inventoried, carries no earlier Git
  history, and accompanies every deployment. Vendor sources retain original
  licenses. Unused React/Vinext/Sites framework code is not in this release.

## 2026-10-30 — compiled execution backend

Added locally authored freestanding C instruction execution, compiled to Wasm, with checked RAM and atomic yields to the existing host adapters. Adaptive dispatch retains the cheaper reference path for short native entries. Existing MAME-derived semantics, GPL and other notices remain; this is not a clean-room licensing claim. Stock/DMC and snapshot identity files stay unchanged. Source, build recipe, differential tests and base64-encoded compiled artifact are included.

2026-10-30: Added an optional GPCE4 C/Wasm reset-boot mode ported from the local unsp.py/soc.py machine model. Original Python oracle is included under reference/gpce4. Real ROM and firmware remain local user inputs. This mode includes IRQ, SPI, LCD, timers and isolated exact-machine snapshots; sound/motion/link/offline custody remain unconnected. Existing default mode and snapshots are retained.

## 2026-10-31 — GPCE4 peripherals and continuity

- Added masked GPIO and enabled peripheral wake independently of CPU IRQ delivery;
  native ROM resumes its sleep loop and clocks. Snapshot ABI v1 is unchanged.
- Observe admitted native sound calls without replacing native busy completion.
  Reuse user-calibrated approximate browser audio (+48 semitones, 2x). Motion
  supplies a bounded input latch consumed by the original firmware.
- Reconnect admitted native packet wrappers to QR relay transport. Different
  compatible BINs may pair. Native code owns Battle/Jogres validation, results,
  animation and Flash writes. This is not physical wire timing emulation.
- R23 offline custody settles native event boundaries after synchronizing at a
  safe UI entry, including native wake from HOME sleep. Unsupported states and
  existing injury/illness remain paused. Transactions retain original care history,
  restore failed changes and clear ephemeral input/audio. No background service
  runs the game while the page is closed.
- Migrate only the explicitly known previous GPCE4 core snapshot with original
  backup retained. Connected sessions cannot be serialized; successful disconnect
  saves before completion. Settled animations may finish after disconnection.
- Regression evidence includes real-ROM native boot/hatch/sleep/wake and two-day
  custody, plus R23/R20 native Battle/Jogres using declared eligible test fixtures,
  cold Flash reload and byte-identical animation snapshot continuation. Physical
  phone performance, accelerometer behavior and speaker waveform remain unmeasured.
- Source, GPL/BSD notices and firmware-local-only release policy remain unchanged.
