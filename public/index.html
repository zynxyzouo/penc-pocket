這個試作能做什麼？＋

可從原生開機畫面設定時間、選蛋與孵化；現有快照仍保留原進度。完整生命週期與實體機驗證尚未完成。手機晃動及聲音預設開啟，首次按開始時依瀏覽器要求授權。

此 GitHub Pages 版本預設沒有配對服務。連線程式已保留，經營者接上相容服務後才能使用 QR。對戰、合體及動畫由 BIN 原生流程執行；BIN 與快照留在各自手機。

原生流程更新目標為每秒 64 次，與桌面預覽一致；實際速度取決於手機效能。開發模式分別顯示畫面 FPS 與 SIM 更新率，尚未按實機校準。遊戲 RTC 仍按真實秒數推進。

Menu、離開網頁與鎖定螢幕會待機。R23 預設離線託管，回來點螢幕會按事件結算：成長繼續，代為餵食、清潔與關燈。既有傷病請先治療；操作選單、尚未孵化或未支援流程會保留剩餘時間。可在上方改選「原機補算」，此模式會有未照顧的後果，離開越久可能等越久。結算期間可點螢幕暫停。原版 TEST4 與 DMC 目前在待機、關閉期間暫停養成；網頁關閉時不會在背景持續執行。

首次啟動需要網路下載 Python / WebAssembly 核心。這一版尚未提供離線啟動；可加入主畫面方便開啟。

橫向採 3:2 寬景：用原背景鏡像延伸兩側，角色與圖示維持比例。補景不增加遊戲判定範圍；選單仍以中央原畫面顯示。
